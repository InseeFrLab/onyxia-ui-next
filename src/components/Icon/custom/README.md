# Custom Icons

This directory is reserved for future approved Onyxia custom SVG icons.

When custom icons are added:

-   use SVG as the source format;
-   wrap them so they remain compatible with the shared `Icon` component
    contract;
-   preserve a meaningful `viewBox`;
-   prefer `currentColor` when the icon should inherit semantic content color;
-   avoid hard-coded presentation colors unless the Design System explicitly
    requires them;
-   keep branding-only assets distinct from ordinary interface icons when the
    Design System makes that distinction explicit;
-   do not duplicate icons that already exist in `@mui/icons-material`.

No custom icons are registered yet in `onyxia-ui-next`.
