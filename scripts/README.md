# Scripts

This directory contains repository maintenance and generation scripts.

Color tokens are generated from the JSON sources under
`src/tokens/source/colors/` through `generateTokens.mjs`.

Typography tokens are generated from the JSON sources under
`src/tokens/source/typography/` through the same script.

Spacing tokens are generated from the JSON sources under
`src/tokens/source/spacing/` through the same script.

Sizing, radius, and icon semantic-size tokens are generated through the same
script.
