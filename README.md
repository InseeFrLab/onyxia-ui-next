# onyxia-ui-next

`onyxia-ui-next` is the progressive successor to
[`InseeFrLab/onyxia-ui`](https://github.com/InseeFrLab/onyxia-ui).

This repository is intentionally initialized with a minimal foundation:

-   single-package architecture;
-   Yarn package management;
-   React, TypeScript, MUI, `tss-react`, and Storybook conventions preserved;
-   no migrated production components yet;
-   no decided token source-of-truth yet;
-   no CI, release, Renovate, or npm publication configuration yet.

## Current Scope

The repository currently contains:

-   base project configuration;
-   empty source directories with placeholder documentation;
-   durable documentation directories;
-   temporary migration documentation directories;
-   a reserved test-app directory.

## Documentation Layout

-   `docs/foundations`: durable design-system foundations
-   `docs/rules`: durable implementation and design-system rules
-   `docs/components`: durable component specifications
-   `docs/migration`: temporary legacy migration notes
-   `docs/decisions`: significant technical and design-system decisions

## Status

No production components, token values, generated token files, Code Connect
mappings, CI workflows, release automation, or npm publishing setup have been
added yet.
